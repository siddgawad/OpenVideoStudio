# Project Skills Index

## Start and coordination

- `/phase-zero` — complete research and planning program.
- `/mcp-health-check` — verify the connected MCP environment.
- `/source-register` — enforce source capture and verification metadata.

## Research

- `/product-landscape` — commercial product and capability map.
- `/open-source-landscape` — discover relevant open-source projects.
- `/repository-due-diligence` — inspect one or more repositories deeply.
- `/model-feasibility` — assess generative and editing model capabilities.
- `/license-cost-audit` — audit licenses, pricing, compute, and “free” claims.
- `/security-consent` — threat model, identity, voice, privacy, and rights review.
- `/nontechnical-ux-review` — consumer usability and accessibility review.

## Product and architecture

- `/canonical-scene-model` — define project, timeline, scene, character, asset, and edit schemas.
- `/architecture-synthesis` — convert approved evidence into architecture decisions.

## Engineering handoff

- `/task-contract` — create a bounded implementation contract.
- `/codex-handoff` — create a complete Codex execution packet.
- `/adversarial-review` — try to disprove a plan, task, architecture, or implementation.
- `/browser-acceptance` — browser-based responsive/accessibility workflow testing.
- `/release-readiness` — verify release evidence without deploying.
